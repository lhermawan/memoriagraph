# Contributing to MemoriaGraph

Thank you for your interest in contributing! 🎉

## How to Contribute

1. Fork the repository
2. Create a new branch: `git checkout -b feature/my-feature`
3. Make your changes and commit: `git commit -m "Add my feature"`
4. Push to your fork: `git push origin feature/my-feature`
5. Open a Pull Request

## Ideas for Contributions

- Add support for more AI clients (OpenAI, Mistral, etc.)
- Build a web UI dashboard for managing entities
- Add entity search and filtering
- Improve context retrieval algorithm
- Add import/export for memories (JSON, CSV)
- Write tests

## Code Style

- Python: follow PEP8
- Keep functions small and focused
- Add docstrings to all public functions

## Questions?

Open an issue and we'll help you out!
